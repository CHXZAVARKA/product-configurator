# 02: Преломление света через один и два осколка

**What to build:** В стенде видно преломление тестовой сетки через один и два перекрывающихся осколка; можно сравнить быстрый вид с неподвижным качественным контролем той же сцены.

**Blocked by:** 01: Свободное движение двух осколков в CAD-камере

**Status:** ready-for-agent

**Owner:** implement-spec worker for ticket 02; integration owner: root orchestrator.

- [ ] Реальное смещение выборки фона по границам/толщине стекла, цветное поглощение и зависимость от направления; не только умножение цвета и additive-блики.
- [ ] Один и два слоя демонстрируются отдельно с одинаковыми сохранёнными позами в сравниваемых режимах.
- [ ] Получен качественный контрольный кадр трассировкой через геометрию и свет; сохранены настройки/метод, ограничения сходимости честно описаны.
- [ ] Сетка видна и меняет положение внутри осколка; тонкие/толстые участки и перекрытие изменяют пропускание. Есть воспроизводимые проверки и браузерные снимки.
- [ ] Измерена стоимость на фиксированном разрешении; модуль можно подключить в общий просмотр, не ломая исходный прототип.
