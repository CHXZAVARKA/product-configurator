# 03: Искажения через настоящий CAD-эльвинг

**What to build:** Без насыпки пользователь смотрит через настоящую CAD-деталь эльвинга на сетку/логотип и меняет положение света и изделия.

**Blocked by:** 01: Свободное движение двух осколков в CAD-камере

**Status:** ready-for-agent

**Owner:** implement-spec worker for ticket 03; integration owner: root orchestrator.

- [ ] Используется предоставленная геометрия эльвинга либо проверенные по ней карты поверхностей и толщины с указанной областью допустимости.
- [ ] Нет произвольного синусоидального рельефа вместо CAD. Ориентация и масштаб совпадают со сборкой.
- [ ] Сетка и пример логотипа искажаются при включении детали; изменение света/ракурса даёт осмысленный отклик, неподвижный эльвинг сам не течёт.
- [ ] Сохранены контрольные лучи/геометрические проверки и браузерное сравнение без/с эльвингом.
- [ ] Результат оформлен самостоятельным модулем/демонстрацией для последующего подключения к глазку.
