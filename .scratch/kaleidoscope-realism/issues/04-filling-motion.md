# 04: Пересыпание набора стёкол со свободным пространством

**What to build:** Пользователь меняет заполнение камеры, поворачивает её и видит перераспределение разнообразных осколков с доступным местом для движения.

**Blocked by:** 01: Свободное движение двух осколков в CAD-камере

**Status:** ready-for-agent

**Owner:** implement-spec worker for ticket 04; integration owner: root orchestrator.

- [ ] Разные формы/размеры из процедурной библиотеки, исходная укладка не является двумя одинаково ориентированными листами Вороного, заполняющими сечение.
- [ ] Показ заполнения учитывает физические оболочки, а не только видимые объёмы; можно сравнить редкую/среднюю/плотную насыпку.
- [ ] Движение даёт скольжение/перераспределение и перевороты там, где хватает геометрического зазора; нет выхода наружу или глубоких исходных пересечений.
- [ ] На нескольких seed проверены динамические/остаточные пересечения, пауза, сон без видимого падения и пробуждение. Пороги не ослабляются для сокрытия дефектов.
- [ ] Запись/воспроизведение поз позволяет сравнивать свет без пересчёта хаотической траектории. Сохраняются замеры активной физики и покоя.
