# Сглаженное стекло и вид из призмы

Запрос от 2026-09-14: включить Shade smooth, сохранить просмотр в реальном времени и добавить вид изнутри призмы.

Результат: отдельная локальная версия на ветке `prototype/realtime-prism`, сервер 3039. Исходники и проверки находятся в `prototypes/PROTOTYPE-realism/elving/`. Новый просмотр использует GPU для CAD-стекла и отдельный проход трёх зеркал. Тяжёлый CPU-контроль доступен по `/PROTOTYPE-elving.html`.

Проверяемый контракт:

- Сглаженные нормали без изменения формы CAD, с сохранением резких рёбер.
- Непрерывное обновление при повороте и работе ползунков.
- Вид от глазка через внутренние зеркала настоящей CAD-призмы.
- Общий GPU-кадр укладывается в 33 мс на проверенном M1 с автоматически выбранным разрешением.
- После остановки действий новые кадры не считаются.

Граница этой версии: зеркальный проход переиспользует одну ортографическую картинку эльвинга. Это ускоряет просмотр, но не воспроизводит всю угловую зависимость преломления. Полная насыпка не включена. Незавершённые задачи прежнего графа реализма остаются незавершёнными.

Доказательства: `realtime-geometry.json` и `realtime-browser.json` в папке evidence, вывод `prism-check.mjs`. Точные команды и ограничения описаны в README стенда.

## Проверенный результат

Все проверки прошли 2026-09-14. Геометрический тест сравнил 2523 луча с CPU-контролем, максимальная разница расстояния составила 0,00000456 мм. Тест зеркального канала проверил 1249 лучей, до 8 отражений. Браузерный тест подтвердил все пункты контракта и p95 24,3 мс при размере стекла 256 × 256 на Apple M1. Старый CPU-контроль прошёл свою проверку по новому явному адресу.

Встроенная вкладка 3039 обновлена и проверена вручную: доступны сглаженное стекло, вращение и вид из призмы. Оставлена на виде из призмы с выключенным автоматическим вращением.
