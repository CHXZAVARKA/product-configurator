# Пошаговый конфигуратор изделий

Отдельный клиентский проект. Первый товар: калейдоскоп «Красивое стекло». Общая основа должна позволить затем сделать конфигуратор лампы KOMPONENT L-01.

## Подтверждено пользователем

- Пошаговый выбор параметров с постоянным 3D-просмотром сбоку.
- Компактная панель текущего шага с минимумом информации.
- Исходное содержание шагов берём из действующего конфигуратора Tilda.
- Сравниваем разные варианты интерфейса до выбора реализации.
- Начинаем с интервью, затем проектируем модули и клиентский сценарий.
- Проект имеет отдельную папку и локальный Git.
