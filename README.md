# Пошаговый конфигуратор изделий

Отдельный клиентский проект. Первый товар: калейдоскоп «Красивое стекло». Общая основа должна позволить затем сделать конфигуратор лампы KOMPONENT L-01.

## Подтверждено пользователем

- Пошаговый выбор параметров с постоянным 3D-просмотром сбоку.
- Компактная панель текущего шага с минимумом информации.
- Исходное содержание шагов берём из действующего конфигуратора Tilda.
- Сравниваем разные варианты интерфейса до выбора реализации.
- Начинаем с интервью, затем проектируем модули и клиентский сценарий.
- Проект имеет отдельную папку и локальный Git.
- Первый сценарий рассчитан на корпоративного заказчика; опираемся на существующую логику и улучшаем её удобство.
- Завершение: передача конфигурации менеджеру, предварительный расчёт, состав заказа, 3D и ссылка на вариант.
- Сначала каталог с 3D-моделями и заглушками там, где модели нет. Полный сценарий пока только у «Авторского»; остальные изделия сейчас не реализуем.
- После выбора «Авторского» показываем собранную рекомендуемую комплектацию с предварительной ценой. Настройки доступны через шаги, меню и нажатие на детали 3D.
- Клиент и сотрудники используют общие возможности оформления: загрузку и размещение изображений, работу со слоями, белилами и лаком. Сегментация, рисование масок и карты нормалей/глубины входят в планируемое направление, их реализация ещё не выбрана.
- Сотрудник подключается при разработке нового дизайна или выбранной помощи с макетом. Перед печатью выполняется техническая проверка, которая не требует обязательной доработки или покупки помощи.
- Доработки сохраняются новыми версиями того же проекта. Клиент согласовывает версию по прежней ссылке, предыдущие варианты сохраняются.
- Новый товар подключает разработчик через описание шагов, правил, цен и 3D-модели.
- Единый конфигуратор предназначен и для самостоятельной работы клиента, и для работы команды. Детская версия относится к последующему этапу.

## Текущий этап

Дополнительная расшифровка учтена в [предложении клиентского флоу v1](docs/client-flow-v1.md): после выбора «Авторского» показываем готовый пример с макетом, 3D и включёнными опциями. Это основа следующей итерации интерфейса; регистрация, хранение ссылок и техническая реализация оптики пока не определены.

По запросу пользователя созданы [четыре макета через imagegen](output/imagegen/2026-09-11/README.md) в стиле действующего сайта Tilda с CAD-референсом «Авторского». Представлены каталог, пошаговая настройка, насыпка с логотипом и призмой, многоцветные кольца. Это визуальное предложение, рабочее приложение ещё не создано.

Собран одноразовый [прототип живой оптики](prototypes/PROTOTYPE-optics/README.md) по навыку `prototype` (logic-ветка): семь STEP-деталей владельца, стёклышки с физикой в камере глубиной 10 мм, отражения от трёх граней призмы, физическое стекло и студийная HDRI. Числовые и браузерные проверки прошли. Открытый вопрос для владельца: при наклоне изделия к горизонтали насыпка уходит из видимой зоны зеркал, нужно сверить размеры камеры с реальным изделием.

Интервью `grill-me` / `grilling`: согласован единый инструмент для клиента и команды, техническая проверка и версии для согласования. [Запись интервью](docs/discovery.md) отделяет подтверждённые решения от идей транскрипции и предложений. Выполнен [разбор актуального Roundprint по codebase-design](docs/audits/roundprint-9f9f364/README.md), включая локальные воспроизведения проблем сохранения. Архитектура, технологический стек, объём первого UI-прототипа и финальный интерфейс ещё не выбраны.

После определения цели: карта решений `wayfinder` в локальном Markdown, проектирование по `codebase-design`, затем UI-прототип по `prototype`. Карта ещё не создана: её назначение и первая группа решений должны следовать из интервью.
