# PROTOTYPE: оптика «Авторского»

Локальная проверка движения и изображения для конфигуратора на основе семи STEP-деталей владельца. Два независимых варианта с общим переключателем: процедурное объёмное стекло и движущаяся фотография. Это визуальный прототип, а не калиброванная модель реального изделия.

## Физическая насыпка

- Камера Ø37,6 × 10 мм. Глубину и почти полное заполнение подтвердил владелец. По умолчанию 64 стекла, два исходных слоя вместо трёх. Это оставляет место для пересыпания и переворотов; 96 доступны отдельно как плотное заполнение.
- Процедурные неправильные осколки: случайные выпуклые контуры из разбиения Вороного, неодинаковые сколы и наклонённые грани. Толщина 2,3–2,6 мм, максимальная ширина 9,1 мм. Палитра и характер поверхности ориентированы на [фото владельца](assets/user-glass-pieces.png); размеры и оптические свойства по нему не измерялись.
- Тела двигаются в пространстве, сталкиваются, переворачиваются. Поворот действительно перемещает стенки камеры, встряхивание задаётся плавным перемещением камеры. Скорость поворота ограничена для устойчивого контакта, поэтому модель догоняет резкое движение ползунка.
- Rapier 0.19.3: миллиметры, `lengthUnit=1000`, шаг 1/240 с, 4 итерации, частота контактов 1000 Гц. Для столкновений используются выпуклые оболочки со скруглением 0,3 мм. Видимая геометрия лежит внутри оболочки. Масса 0,01 кг служит численной настройкой, это не измеренная масса осколка. CCD отключён; дополнительная коррекция границы удерживает всю оболочку внутри цилиндра.
- Сон: три последовательных окна по 250 мс, в каждом средние положения всех тел дрейфуют меньше 0,3 мм, а средние ориентации меняются меньше 0,06 рад. Мгновенное отклонение, включая поворот с плечом 5 мм, ограничено 2 мм. Так мелкое численное качание вокруг одного места не удерживает решатель включённым бесконечно; направленное пересыпание не проходит этот критерий. После этого прекращаются шаги мира и перерисовки. Наклон и встряхивание будят насыпку, изменение цвета и света требует только нового изображения.

## Свет и эльвинг

Одно изображение насыпки 384² используется во всех отражениях. Карта трёх CAD-зеркал рассчитывается при смене поля зрения. Коридор длиной 180 мм и внутренним радиусом 6,14 мм сохранён; каждое отражение не запускает новый расчёт стекла.

Цветное пропускание учитывает толщину и угол поверхности через экспоненциальное поглощение, перекрытия темнеют, грани отражают HDRI. Светящийся фон регулируется отдельно. На поддерживаемых GPU промежуточное изображение HDR сохраняет яркость до прохождения через цветные слои; предусмотрен обычный 8-битный запасной вариант.

Статический процедурный рельеф эльвинга меняет нормаль поверхности. Приближённое преломление с IOR 1,52 смещает фон и внутренний логотип; кривизна даёт пятна концентрации света. Рельеф закреплён в изделии и сам по себе не колышется. Ползунок «Неровность эльвинга» позволяет сравнить его с ровной поверхностью. Камера и глазок используют один материал подсветки.

Ограничение: нет полноценной трассировки света через каждый осколок, многократного внутреннего преломления и физически точных каустик. Изображение в зеркалах повторяет проекцию насыпки, а не весь объём с новым параллаксом. Соответствие настоящему образцу и работа на слабых телефонах пока не подтверждены.

## Живое фото

`PROTOTYPE-photo.html` перемещает и поворачивает фотографию целиком. Пространственная волна удалена. Есть оригинал, движение и зеркальное повторение, перетаскивание, пауза, скорость и сила движения.

Можно загрузить PNG, JPEG или WebP до 20 МБ. Пропорции сохраняются с центральным кадрированием, текстура уменьшается максимум до 2048 пикселей по длинной стороне. Прозрачность ложится на светлый фон. Файл декодируется в браузере и никуда не отправляется. При ошибке предыдущая картинка остаётся; запоздавшая загрузка не заменит выбранную позже. Кнопка «Вернуть фото стекла» восстанавливает исходник.

Движение фотографии не пересыпает отдельные кусочки. Встроенное фото уже содержит зеркальный узор; для варианта с собственным материалом можно загрузить фото самой насыпки. При reduced motion анимация первоначально остановлена, скрытая вкладка не рисует кадры.

## Запуск

Из этой папки:

```sh
python3 build.py
python3 preview.py
```

Открыть [физический просмотр](http://127.0.0.1:3027/PROTOTYPE-viewer.html) или [живое фото](http://127.0.0.1:3027/PROTOTYPE-photo.html). Оба HTML также открываются локально, ресурсы встроены, сеть не требуется. Нужен WebGL, для 3D WebGL 2. Сборка Python не требует npm.

`model.js` содержит физику и генераторы геометрии; `fast-optics.js` отвечает за материал и зеркала; `app.js` связывает их с интерфейсом. `photo.js` независим от физики и 3D-библиотек. HTML собираются из исходников, вручную их не редактировать. Источники и лицензии: [assets/SOURCES.md](assets/SOURCES.md).

## Проверки

Запуск из этой папки, Node 26:

```sh
node evidence/startup-sleep-check.mjs 64
node evidence/startup-sleep-check.mjs
node evidence/contact-check.mjs
node evidence/numerical-checks.mjs
node evidence/pouring-check.mjs 64
node evidence/glass-geometry-check.mjs
node evidence/current-performance.mjs
```

- `startup-sleep-check.json`: начальное встряхивание полной камеры на трёх seed, остановка мира и поз без остаточного пересечения больше 0,3 мм.
- `contact-check.json`: независимые разделяющие оси для всех пар, 96 стёкол, три seed, восемь секунд воздействий и восемь секунд укладки. Проверяет проникновения, границы и сон.
- `numerical-checks.json`: заполнения 0/24/48/72/96, наклоны и встряхивания, пауза, укладка, пробуждение и 441 луч в CAD-зеркалах.
- `pouring-check.json`: заполнение центрального треугольника при горизонтальном положении и перемещение при повороте вокруг оси. `pouring-baseline.json` фиксирует исходную проблему редкой насыпки из 36 стёкол.
- Геометрическая проверка: 288 процедурных поверхностей на трёх seed замкнуты, имеют согласованную ориентацию и не выходят за физическую оболочку.
- `current-performance.json`: CPU-время физики 96 стёкол, не FPS браузера. Старые `fast-*`, `realism-*`, `browser-check*` и `physics-performance.json` относятся к предыдущим версиям.

История выбора решателя: [простая физика и сон](../../docs/research/2026-09-11-simple-physics-freeze.md), [контакты плотной насыпки](../../docs/research/2026-09-11-dense-pile-contacts.md). Пошаговый клиентский интерфейс и печатные слои остаются отдельной работой.

### Проверка плотного варианта из 96 стёкол, 11 сентября (5dac29e)

Все перечисленные численные проверки прошли. После стартовой тряски 96 стёкол останавливаются за 1,5 / 2,75 / 1,75 с на трёх seed; остаточное проникновение оболочек 0–0,231 мм. При повторных воздействиях максимальное измеренное проникновение 0,411 мм, после укладки 0 мм, выходов за границы нет. Это допустимая погрешность прототипа, не точность настоящего контакта стекла.

Центральный треугольник горизонтального просмотра перекрыт на 95,3%, ранее на 39,6%. После поворота горизонтальной камеры среднее перемещение в её системе координат 2,16 мм. Медленный вертикальный поворот может увлекать стекло вместе с дном за счёт трения, поэтому тест не требует скольжения именно в этом положении.

CPU-физика на Apple M1 / Node 26.7: медиана 12,28 мс, p95 16,96 мс на логический кадр из четырёх шагов. Это измерение активного движения; после сна шаги не вызываются.

В браузере проверены камера, глазок, пустой вид, пример F, переключение рельефа и выключение подсветки. Снимки `procedural-chamber.png`, `procedural-eye.png`, `elving-flat.png`, `elving-relief.png`, `backlight-off.png` относятся к новой сборке. В фото-варианте пауза сохраняет время и счётчик кадров, волнового изменения координат нет. Кнопка возврата встроенного PNG проходит общий декодер; выбор произвольного файла через системный диалог в этой итерации не проверялся.

### Запас пространства, 64 стекла по умолчанию

После замечания владельца третий исходный слой убран. Доля объёма оболочек без скругления снизилась с 52,2% до 34,8%; запас нужен также для коллайдеров и переворота граней. В горизонтальном тесте покрытие треугольника 89,7%, среднее перемещение после поворота 2,31 мм, выхода за стенки нет. Актуальный результат: `evidence/pouring-check.json`; сон после встряхивания проверяется отдельно в `startup-sleep-check-64.json`. Форма стекла и решатель не менялись, проверки 96 стёкол остаются проверками повышенной плотности.
